# Доработки

Опишите задачу и приложите пример вводных. Для исправления формулы покажите ожидаемый результат и источник методики. В pull request укажите, какие страницы проверили.

Используйте синтетические отчеты. Уберите клиентские данные, учетные записи и токены из примеров. Сохраните уведомление об авторстве и MIT-лицензию.

# Contributing

Describe the problem and include reproducible sample inputs. For formula changes, provide the expected result and the source of the methodology. Use synthetic reports and preserve the copyright notice and license.
